# 检测区间与复检

采样日期选择限量标准[start,end)，不使用报告出具日。同产品同残留项目在采样日须恰有一条有效标准，方法须在适用范围内。浓度统一mg/kg，ug/kg与ppb乘0.001，ppm等于mg/kg。检出限LOD必须大于0。

定量值以[value,value]记录，低于LOD的定量值拒绝。ND或<LOD以[0,LOD)记录，<后的数值必须等于报告LOD。区间上界≤限量为PASS，下界>限量为FAIL，其余UNCERTAIN。<0.01相对0.005限量为不确定，不能当零。

复检relation指向原报告，必须同样本、同批次、同产品、同残留项目、同方法、同采样日，报告日严格更晚。引用环、悬空引用与异样本引用隔离。每样本/项目只允许一个原始报告根。有效复检按reported、version取最新；并列结果矛盾拒绝。其他残留项目不因复检被覆盖。批次按FAIL>UNCERTAIN>PASS取最高风险等级。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

同一报告ID的多个版本先选最高version，再构建复检引用链；历史版本留作采信证据，不重复参与最终项目判定。

## 封存保留裁决定义

**已出证**：运行复核状态为“通过”、对账 `balanced` 为真、归档 `ready` 为真。三者缺一即未出证，不得进入压缩候选。

**到期**：出证时间（复核通过时写入 `issued_at`，缺失时退回运行清单的 `generated_at`）距裁决时刻已达到 `RETENTION_DAYS`，默认 0 天即出证即到期。

**可压缩记录**：运行已出证、已到期，且该记录不被任何未完结复检引用、所属批次也不在复核中。压缩只移除重复原始副本（`measurements`/`reports`/`rows` 的原件）与源文件明文（`source_b64` 改存 zlib 压缩的 `source_z`），以下内容必须留在记录里：

- 摘要：运行 `manifest`、归档 `archive`、对账 `reconcile`、计算 `calculations`、业务合计 `business`；
- 隔离原因：`quarantine` 全部字段（含来源行、ID、原因码、原值摘要）；
- 复检引用关系：每条记录保留 `relation`（`retest_of`）与 `record_sha256`；
- 可还原证据：`evidence` 逐条保留 ID、样本、批次、项目、方法、采样/报告日、结果、区间、限量、结论与记录摘要，可按批次、样本、复检关系还原。

**阻塞对象**：一条记录只要仍被未完结复检引用（同一来源运行内指向它的复检尚未进入采纳结论，或引用它的批次仍在复核），或所属运行仍在复核，就必须保留原件并在账内列出阻塞类型、来源运行、引用记录与原因。跨运行的相同记录 ID 不互相阻塞，仅有当引用运行自身没有该目标 ID 时才视为悬空引用。

**保留账版本**：以“运行集合 + 复核状态 + 出证时间 + 源摘要 + 规则版本”计算来源键；同源再次裁决返回既有版本，不产生新账。保留账复核需提交当前版本，陈旧复核返回 409。归档放行只认当前保留账：未复核通过、复核退回或来源已变（过期）均返回 409。

**失败回滚**：压缩与出账在同一事务内完成；任一步失败整体回滚，运行正文、出证时间与旧保留账保持不变。
