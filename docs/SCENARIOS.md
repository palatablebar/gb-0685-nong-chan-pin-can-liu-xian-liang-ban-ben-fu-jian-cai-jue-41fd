# 检测场景

12个苹果样本分4批，每个样本初检P01为<0.01mg/kg，采样日标准限量0.005，因此不确定。次日同样本同方法复检0.004且LOD0.001，判为PASS并替代原报告。每样本P02为30ug/kg，超过0.02mg/kg，仍FAIL。最终24项目，12PASS、12FAIL，四批均FAIL。脏批额外含缺LOD、同版冲突、错列、空行与重复表头。

## 封存保留场景

运行批次复核通过后即算已出证（默认保留期0天，出证即到期）。已出证批次在 `/m8_retention` 可整体压缩：

- 无待复核批次、无未完结复检时，四批36条记录全部进入压缩范围，原文改为源摘要+zlib 源文件，证据清单、隔离原因与复检引用留在账内；
- 若另有来源运行提交了指向某原件的未完结复检（例如仅提交 00002 复检、尚未复核），该原件所在批次转为“保留”，账内列出阻塞对象；其余批次照常压缩；
- 批次被退回重开时，已压缩的该批次自动恢复为完整原件，保留账标记“恢复”；
- 同一来源重复裁决返回同一保留版本；归档导出只在当前保留账复核通过且来源未变时放行。
